# PromptEdit Landing Page Redesign

A modern cinematic landing page redesign for PromptEdit.com built with Next.js, React, Tailwind CSS, Framer Motion, and Lucide Icons.

This project was created as part of a front-end developer application focused on improving the UI/UX experience for AI content creators.

---

## Features

- Modern AI SaaS landing page design
- Fully responsive mobile-first layout
- Cinematic UI inspired by creator platforms
- Framer Motion animations
- Interactive mobile navigation
- Embedded Wistia video section
- Pricing sections
- AI tools showcase
- Templates library showcase
- Creator testimonials
- Tailwind CSS styling
- Premium gradients and glassmorphism effects

---

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide React Icons
